# RGMS Express Backend REST API

Official Express.js REST API & MongoDB Database Backend for RGMS Smarthome & Security Store.

## Features
- **JWT Admin Authentication**: Secure login, token issue & verification.
- **Product Inventory Management**: REST API endpoints for CRUD operations on products.
- **Cloudinary Image Upload**: Direct image file & Base64 image upload to Cloudinary.
- **Customer Contact Messages API**: REST API for public contact submissions & admin inquiry management.
- **MongoDB / File JSON Database**: Supports MongoDB with local JSON database fallback.

## Running Locally
```bash
npm install
npm run dev
```
Express server runs on `http://localhost:5000/api`.
